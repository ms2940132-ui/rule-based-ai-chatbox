# Rule-Based AI Chatbot
## Project Overview
This project is a simple rule-based AI chatbot developed in C++.
The chatbot uses predefined rules and if-else decision-making
to identify different user inputs and provide appropriate responses.
## Project Objectives
The main objective of this project is to demonstrate basic AI
concepts and programming logic through a simple conversational
chatbot.
## Key Features
- Continuous conversation using a while loop
- Input sanitization
- Lowercase conversion
- Whitespace handling
- Multiple greeting variations
- Knowledge base with multiple intents
- If-else decision-making
- Predefined chatbot responses
- Fallback response for unknown inputs
- Multiple exit commands
- Help menu

## How to Run
1. Download or clone this repository.
2. Open `chatbot.cpp` in a C++ compiler or IDE.
3. Compile the program.
4. Run the program.
5. Enter a message when prompted.
6. Type `bye`, `goodbye`, `exit`, or `quit` to end the conversation.
## Project Requirements
This project fulfills the following requirements:
### Input Loop
A continuous while loop allows the user to interact with the chatbot multiple times.
### Sanitization
User input is converted to lowercase and unnecessary spaces and punctuation are handled.
### Knowledge Base
The chatbot contains multiple predefined intents and responses.
### Fallback
Unknown inputs receive a default response instead of causing the program to stop.
### Exit Strategy
The chatbot recognizes multiple exit commands and ends the conversation cleanly.
